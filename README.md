# 大别红魂·新县导览

这是《大别红魂·新县导览》的第一版手机端静态网站。

## 当前功能

- 普通网址访问
- NFC 来源入口识别：在网址后添加 ?source=nfc
- 首页与五个主题栏目
- “沿总书记足迹”四阶段路线
- 已核验点位卡
- 外部地图搜索入口
- PCB 正反面视觉展示

## 暂未包含

- 购买、消费、商城或支付功能
- 语音功能
- AR 功能
- 后台管理
- NFC 写入操作
